# Product Context

## Why This Project Exists

### The Problem
Circuit simulation is critical for modern electronics development, yet existing tools are:
- **Complex**: Steep learning curves, cryptic interfaces
- **Disconnected**: Simulation separate from understanding
- **Expensive**: Commercial tools cost thousands
- **Inaccessible**: Require deep expertise to use effectively

### The Opportunity
Engineers and students need circuit simulation because:
- **Cost Savings**: Simulation costs $0, prototypes cost $500+
- **Speed**: Iterate in seconds vs weeks for physical builds
- **Safety**: Explore circuit limits without damage
- **Understanding**: See invisible currents and transients

## How It Should Work

### User Journey
1. **Define Circuit**: Simple Python API or import schematic
2. **Simulate**: One command, automatic backend selection
3. **Visualize**: Interactive Plotly reports open instantly
4. **Understand**: Clear insights, not just raw data
5. **Share**: Export beautiful reports for documentation

### Key Differentiators
- **Dual Audience**: Professional power with educational clarity
- **Beautiful Reports**: Not just data, but insights
- **MCP-Ready**: First simulation platform built for AI integration
- **Docker-Simple**: Complex setup eliminated

## User Experience Goals

### For Professionals
- Faster than building prototypes
- Reports suitable for design reviews
- Confidence in results
- Integration with existing workflows

### For Students
- Learn by doing, not just reading
- See theory come alive
- Build intuition through interaction
- Progress from basics to professional

### For Educators
- Ready-to-use curriculum
- Interactive demonstrations
- Assessment tools
- Student engagement

## Product Principles
1. **Accessibility First**: If it's not easy, it's not useful
2. **Beautiful Matters**: Professional tools should look professional
3. **Education Integrated**: Not bolted on, but built in
4. **Open Foundation**: Core features free forever
5. **AI-Native**: Built for the age of AI assistants
