## Circuit Data Model Analysis

### Overview

The circuit data model in this codebase uses a **simplified, component-based representation** that abstracts electronic circuits into a list of components connected at nodes. The model is designed to be easily converted to SPICE format for simulation.

### Core Data Structure

The main representation is the `Circuit` class (`src/circuit_sim/circuit.py`):

```python
class Circuit:
    name: str                          # Descriptive circuit name
    components: List[Dict[str, Any]]   # List of component dictionaries
    nodes: set                         # Set of node IDs (always includes 0 for ground)
    _simulation_results: Any          # Cached simulation results
```

### Component Representation

Components are stored as **dictionaries** within the `components` list. Each dictionary contains:

| Component Type | Dictionary Keys |
|----------------|-----------------|
| Resistor | `type`, `name`, `node1`, `node2`, `resistance` |
| Capacitor | `type`, `name`, `node1`, `node2`, `capacitance` |
| Inductor | `type`, `name`, `node1`, `node2`, `inductance` |
| Voltage Source | `type`, `name`, `positive`, `negative`, `dc_value` |
| Current Source | `type`, `name`, `positive`, `negative`, `dc_value` |
| BJT Transistor | `type`, `name`, `collector`, `base`, `emitter`, `model` |
| Diode | `type`, `name`, `anode`, `cathode`, `model` |
| Op-amp | `type`, `name`, `vplus`, `vminus`, `vout`, `model` |

### Key Design Patterns

1. **Node System**: Nodes are integers where `0` represents ground. String nodes like `"gnd"` are automatically converted to `0`.

2. **Builder Pattern**: Components are added using fluent method chaining:
   ```python
   circuit = Circuit("RC Filter")
       .add_voltage_source("V1", positive=1, negative=0, dc_value="5V")
       .add_resistor("R1", node1=1, node2=2, resistance="1k")
       .add_capacitor("C1", node1=2, node2=0, capacitance="1u")
   ```

3. **Value Parsing**: Component values use human-readable notation (e.g., "1k", "10u", "3.3V") parsed by `parser.py`.

4. **SPICE Conversion**: The `PySpiceBuilder` class converts this simplified model to PySpice for simulation.

### Data Flow

```
SPICE/KiCad Netlist → SpiceParser/KicadParser → Circuit Object 
                                                   ↓
                              PySpiceBuilder → PySpice Circuit
                                                   ↓
                              SimulationEngine → SimulationResults
```

### API Layer

The API layer (`src/api/models/circuit.py`) uses Pydantic models for validation:
- `ComponentType` (Enum): RESISTOR, CAPACITOR, INDUCTOR, VOLTAGE_SOURCE, CURRENT_SOURCE
- `ComponentInput`: Validated component data
- `CircuitCreate`: Full circuit creation request

### Summary

The circuit model is a **lightweight, Pythonic representation** that:
- Uses dictionaries for components (flexible, JSON-serializable)
- Supports common passive and active components
- Automatically tracks nodes based on component connections
- Converts seamlessly to SPICE for simulation
- Provides a clean builder-style API for circuit construction
