## Research Summary: Python Circuit Schematic Libraries and SVG Output

I've installed and tested both libraries. Here's what I found:

### schemdraw (v0.22)

**SVG Output Capabilities:**
- **Native SVG support** - Direct SVG generation via matplotlib backend
- Use `drawing.save('filename.svg')` to save as SVG
- Use `drawing.get_imagedata('svg')` to get SVG as bytes
- Supports 10 image formats: eps, jpg, pdf, pgf, png, ps, raw, rgba, svg, tif

**Key Features:**
- 247+ circuit element types (resistors, capacitors, inductors, transistors, ICs, etc.)
- Element-based API with manual placement and automatic routing
- Rich labeling and annotation support
- Part of the matplotlib ecosystem (uses matplotlib figures)
- Pythonic, object-oriented API

**Best for:** Creating circuit schematics programmatically with fine control over layout

### lcapy (v1.26)

**SVG Output Capabilities:**
- **SVG support via pdf2svg conversion** (requires external `pdf2svg` tool installed via Homebrew)
- Use `circuit.draw('filename.svg')` to generate SVG
- Internally generates TikZ/LaTeX, converts to PDF, then to SVG

**Key Features:**
- Primary purpose is **circuit analysis** (symbolic and numeric)
- Netlist-based circuit description
- Can analyze circuits and draw schematics from the same description
- Supports multiple styles: American, British, European
- Extensive analysis: DC, AC, transient, noise, Laplace, state-space

**Best for:** Circuit analysis with schematic visualization, or generating schematics from netlists

### Comparison Summary

| Feature | schemdraw | lcapy |
|---------|-----------|-------|
| SVG Output | ✅ Native | ✅ via pdf2svg |
| Primary Use | Drawing | Analysis + Drawing |
| API Style | Element-based | Netlist-based |
| Circuit Analysis | ❌ | ✅ |
| Element Library | 247+ types | Basic set |

### Recommendation

- **For pure schematic drawing**: Use **schemdraw** - simpler, native SVG, more elements
- **For circuit analysis + visualization**: Use **lcapy** - provides both analysis and drawing
