## Summary: HTML Report Generation Codebase Structure and Integration Points

### Core Architecture

The HTML report generation system is located in `src/circuit_sim/reports/` and consists of the following key components:

#### 1. **Main Generator** (`src/circuit_sim/reports/generator.py`)
- **`ReportGenerator`** class - the primary API entry point
- Uses Jinja2 for templating
- Integrates with `PlotlyChartGenerator` and `MetricsCalculator`
- Key methods:
  - `generate_report(circuit, results, report_type, output_format, output_path)` - generates reports
  - `_prepare_report_data()` - aggregates all data for templates
  - `_analyze_circuit()` - extracts component information
  - `_process_results()` - processes simulation data

#### 2. **HTML Builder** (`src/circuit_sim/reports/builders/html_builder.py`)
- **`HTMLBuilder`** class - renders HTML using Jinja2 templates
- Converts Plotly figures to HTML strings
- Handles template context preparation

#### 3. **Charts** (`src/circuit_sim/reports/charts/plotly_charts.py`)
- **`PlotlyChartGenerator`** class - creates interactive Plotly visualizations
- Creates different charts based on analysis type:
  - DC: voltage bars, current bars
  - Transient: voltage/time, current/time
  - AC: Bode plots (magnitude, phase)

#### 4. **Templates** (`src/circuit_sim/reports/templates/`)
- **`base.html`** - base template with common structure, styling, and includes
- **`detailed.html`** - comprehensive report (extends base)
- **`quick.html`** - quick summary template
- **`executive.html`** - executive summary template
- **`styles/`** - CSS files for styling

#### 5. **Utilities**
- **`metrics.py`** - `MetricsCalculator` computes performance metrics (power, bandwidth, phase margin, transfer function analysis)
- **`formatting.py`** - formatting utilities for units and values

### Integration Points

1. **Entry from User Code**: `simulate_circuit_synth.py` creates `ReportGenerator` and calls `generate_report()`:
   ```python
   from circuit_sim.reports.generator import ReportGenerator
   report_generator = ReportGenerator()
   report_path = report_generator.generate_report(circuit, results, report_type="detailed")
   ```

2. **Data Flow**: `Circuit` + `SimulationResults` → `ReportGenerator` → `MetricsCalculator` + `PlotlyChartGenerator` → Jinja2 Templates → HTML Output

3. **Output Location**: Reports are saved to `simulation_reports/` directory (or custom path)

### Report Types
- `quick` - minimal summary
- `detailed` - comprehensive analysis with all charts and metrics
- `executive` - high-level summary for management
