## Report Templates Storage

**Location:** `src/circuit_sim/reports/templates/`

The templates use **Jinja2** templating and include:

| File | Purpose |
|------|---------|
| `base.html` | Base template - loads Plotly.js from CDN, defines HTML structure |
| `detailed.html` | Full analysis report with all charts, metrics, component tables |
| `quick.html` | Condensed summary report with primary chart only |
| `executive.html` | Executive-level summary |
| `styles/` | CSS stylesheet subdirectory |

The template directory is loaded by `ReportGenerator` using Jinja2's `FileSystemLoader`:
```python
self.env = Environment(
    loader=FileSystemLoader(str(self.template_dir)),
    autoescape=select_autoescape(["html", "xml"]),
)
```

## Chart Embedding

**Chart Generation:** `src/circuit_sim/reports/charts/plotly_charts.py`
- `PlotlyChartGenerator` class creates Plotly figures for DC, transient, and AC analyses
- Uses `plotly.graph_objects` and `plotly.subplots.make_subplots`

**Chart to HTML Conversion:** `src/circuit_sim/reports/builders/html_builder.py`
- `HTMLBuilder._generate_charts_html()` converts Plotly figures to HTML:
```python
chart_html = chart_fig.to_html(
    include_plotlyjs="cdn", 
    div_id=f"chart-{chart_name}"
)
```

**Template Rendering:** Templates access charts via `charts_html` dictionary:
```jinja2
{% if charts_html %}
    {% for chart_name, chart_html in charts_html.items() %}
        <div class="chart-container">
            {{ chart_html | safe }}
        </div>
    {% endfor %}
{% endif %}
```

The `| safe` filter is critical - it tells Jinja2 not to escape the HTML content (since Plotly already provides safe HTML).

**External Dependencies:**
- Plotly.js loaded from CDN: `https://cdn.plot.ly/plotly-2.26.0.min.js`
- MathJax for equations (in detailed reports)
