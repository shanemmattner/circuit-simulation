The `auto-eda` library uses `kicad-cli export_svg()` which exports **existing** KiCad schematics to SVG - it doesn't generate schematics from scratch.

- Purpose-built for circuit schematic generation
- Native SVG output
- Active maintenance
- Clean Python API
- Built-in component library
