## Summary

I added validation logic to check that current values match for valid series connections. This is important in electronics because when components are connected in series, the same current flows through all components - so their current ratings must match.

### Changes Made

**1. `lib/component_validation.py`:**
- Added `SeriesComponent` dataclass with `name` and `current` fields
- Added `validate_series_connection()` function that:
  - Validates at least 2 components are provided
  - Checks for negative or invalid current values
  - Verifies all current values match within a configurable tolerance (default 1mA)
  - Returns a `ValidationResult` with appropriate errors if validation fails

**2. `tests/test_component_validation.py`:**
- Added imports for `SeriesComponent` and `validate_series_connection`
- Added 11 new tests covering:
  - Valid series connections with matching currents
  - Invalid connections with mismatched currents
  - Edge cases (single component, empty list, negative/invalid values)
  - Custom tolerance functionality

### Usage Example
```python
from lib.component_validation import SeriesComponent, validate_series_connection

# Two LEDs with matching current (20mA) - valid
components = [
    SeriesComponent(name="LED1", current=0.020),
    SeriesComponent(name="LED2", current=0.020),
]
result = validate_series_connection(components)
# result.is_valid = True

# Two LEDs with different currents - invalid
components = [
    SeriesComponent(name="LED1", current=0.020),
    SeriesComponent(name="LED2", current=0.035),  # 35mA
]
result = validate_series_connection(components)
# result.is_valid = False
# result.get_error_messages() shows the mismatch
```
