## Summary: HTML Report Generation System

The codebase has a well-structured report generation system for circuit simulation results. Here's how it works:

### Core Architecture

1. **Main Entry Point (`src/circuit_sim/reports/generator.py`)**
   - `ReportGenerator` class is the main orchestrator
   - Uses Jinja2 for templating
   - Coordinates chart generation, metrics calculation, and data preparation
   - Supports multiple report types: `quick`, `detailed`, `executive`

2. **HTML Builder (`src/circuit_sim/reports/builders/html_builder.py`)**
   - `HTMLBuilder` class handles HTML file generation
   - Converts Plotly chart objects to HTML using `to_html()` method
   - Uses CDN for Plotly.js (`include_plotlyjs="cdn"`)
   - Prepares template context with charts and metadata

3. **Charts Generation (`src/circuit_sim/reports/charts/plotly_charts.py`)**
   - `PlotlyChartGenerator` creates interactive Plotly figures
   - Supports DC analysis (bar charts for voltages/currents)
   - Supports transient analysis (line charts for voltage/current vs time)
   - Supports AC analysis (Bode plots for frequency response)
   - Uses a color palette for consistent styling

4. **Templates (`src/circuit_sim/reports/templates/`)**
   - `base.html` - Base template with header, footer, and includes Plotly/MathJax
   - `detailed.html` - Detailed report with full analysis (components, results, transfer functions)
   - `executive.html` - Executive summary format
   - `quick.html` - Quick summary format
   - Uses CSS styles in `styles/` directory

5. **Utilities (`src/circuit_sim/reports/utils/`)**
   - `formatting.py` - `format_value()`, `format_units()` for human-readable values
   - `metrics.py` - `MetricsCalculator` for computing circuit metrics (bandwidth, gain, etc.)

### Data Flow

```
Circuit + SimulationResults
        ↓
ReportGenerator.generate_report()
        ↓
  1. _prepare_report_data() → gather metadata, circuit analysis, charts, metrics
  2. _generate_html() → delegate to HTMLBuilder
        ↓
HTMLBuilder.build()
        ↓
  1. _prepare_template_context() → generate chart HTML from Plotly figures
  2. Render Jinja2 template
  3. Write HTML file
```

### Key Features

- **Interactive Charts**: Plotly-based interactive charts embedded in HTML
- **Math Support**: MathJax for rendering mathematical equations (transfer functions)
- **Multiple Report Types**: quick, detailed, executive formats
- **Custom Jinja2 Filters**: `format_value`, `format_units`, `format_time_duration`
- **Analysis-Specific Views**: Different visualizations for DC, transient, and AC analysis
